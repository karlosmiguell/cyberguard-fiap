# CyberGuard FIAP

Treino interativo contra golpes digitais, LGPD e boas práticas, feito para o Security Day FIEB.
Site estático (HTML, CSS e JavaScript): sem servidor, sem login e sem coleta de dados.
O progresso fica só no navegador de quem joga.

- 5 fases de e-mails com ferramentas de investigação (20 mensagens)
- Minijogos: Caça-Golpe, Quiz, Dados e LGPD, Incidentes e Senha forte
- Checklist imprimível e conquistas
- Código de resultado e placar da turma para o projetor (`#/placar`)

A organização (Atlântica Serviços) e todos os domínios usados nos exemplos são fictícios.

Projeto inspirado no Hackudinhos (Faculdade de Defesa Cibernética), reescrito do zero.
